# 1)	Admin Dashboard for Product & User Management 

Modern Admin Dashboard for managing products, categories, and users in an e-commerce system.

🌐 Live: https://dashboard-ecom-pi.vercel.app/

## Stack
Next.js · TypeScript · TailwindCSS · TanStack Query · Vercel

## Highlights
- Full CRUD for Products, Categories & Users
- Optimized server-state management
- Responsive, clean UI
- Scalable folder structure

Run locally:
```bash
npm install
npm run dev
```
